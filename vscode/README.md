| Setting                                | Description                                      |
|----------------------------------------|--------------------------------------------------|
| karateDebug.logLevel                   | Set the logging level for Karate Debug.         |
| karateDebug.logFilter.exclude          | Exclude specific patterns from logs.            |
| karateDebug.logBreakpoints             | Configure breakpoints for debugging.             |
| karateDebug.javaHome                   | Home directory for Java.                         |
| karateDebug.matchDiagnostics            | Enable/disable match diagnostics.                |
